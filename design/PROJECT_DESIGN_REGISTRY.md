# Project Design Registry — NyayaVault (AI for Lawyers, HackIndia)

Comparison vs the three most recent rulebook-era projects, from
their recorded design constitutions (previous project screenshots
were not on file for inspection — noted honestly).

## This project

- Concept: "A law library at first light" — parchment desk under an
  oxblood sky; statute shelves, an ask desk, a grounding ledger; an
  authority constellation above.
- Palette: oxblood `#5c1a24` + brass `#b08d3c` on parchment
  `#f7f1e3`; per-Act star colours (gold Constitution, green IT Act,
  blue CPA, rose Contract Act).
- Type: Georgia serif display + system sans body (Devanagari-capable
  stack). Layout: full-bleed hero → constellation canvas →
  three-column (shelves | ask+answer | ledger).
- Signature interaction: drag-to-spin authority constellation with
  cross-reference lines; click a star to open its provision;
  research-brief generation with download; grounding ledger showing
  routes and budget.
- 3D: canvas perspective-projection authority constellation, fixed
  Act sectors, cross-reference lines, click/arrow-key navigation,
  reduced-motion static fallback, shelves-list 2D fallback.

## Compared projects

1. **NoteVault Bharat (BharatCode Build League, 2026-11-05)** —
   ink navy `#1b2a4a` + marigold `#f0a13a` on cream `#fdf6e9`;
   hero + galaxy + two-column (ask+notes | routing+budget); tag-hash
   constellation. DIFFERENCE: NyayaVault is parchment + oxblood +
   brass (not navy + marigold), a three-column library with statute
   shelves and a grounding ledger (not a two-column desk), and an
   authority constellation with fixed Act sectors and
   cross-reference lines (not a tag-hash galaxy); the interaction is
   consulting provisions and generating briefs, not organising notes.
2. **Digest Room (Flip the Switch, 2026-11-05)** — deep slate
   `#0F1419` + signal lime `#A3E635`, mission-control room, chat
   timeline hero, mono log voice, CSS depth pipeline. DIFFERENCE:
   NyayaVault is a light parchment library (not a dark console), a
   constellation of authorities (not a chat timeline), serif display
   type (not sans + mono); no room list, no agent log voice.
3. **Spec Ghost (Kiroween, 2026-11-03)** — near-black brown +
   candlelight amber, Georgia serif, 860px single-column candlelit
   document, "a ghost is a question, not a bug". DIFFERENCE:
   NyayaVault shares Georgia serif but nothing else — it is a bright
   parchment library with a wide hero + constellation + three-column
   grid, not a narrow dark document; brass is a library accent, not
   candlelight; the interaction is turning a map of authorities and
   generating briefs, not reading a haunted spec.

Verdict: recognisably different in concept, palette, type, layout,
interaction and motion.
